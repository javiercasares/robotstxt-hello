┌─────────────────────────────────────────────────────────────────┐
│ 1. ARCHIVOS A COPIAR                                            │
└─────────────────────────────────────────────────────────────────┘

  ✓ robotstxt-updater.php  →  Copiar a la raíz del plugin
  ✓ update.json            →  Crear en la raíz del plugin


┌─────────────────────────────────────────────────────────────────┐
│ 2. CÓDIGO PARA EL ARCHIVO PRINCIPAL (al final del archivo)     │
└─────────────────────────────────────────────────────────────────┘

// Initialize ROBOTSTXT updater (auto-configures from plugin headers).
require_once __DIR__ . '/robotstxt-updater.php';
Robotstxt_Updater::init( __FILE__ );


┌─────────────────────────────────────────────────────────────────┐
│ 3. HEADER NECESARIO EN EL PLUGIN (añadir al bloque de headers) │
└─────────────────────────────────────────────────────────────────┘

/**
 * Plugin Name: Mi Plugin
 * Version: 1.0.0
 * Gitea Plugin URI: ROBOTSTXT/mi-plugin
 * ...otros headers...
 */


┌─────────────────────────────────────────────────────────────────┐
